## 🇬🇧 English

### 📌 About The Project

**Downsize Image** is a fast, web-based tool designed to help users quickly reduce image file sizes (KB/MB) and adjust image dimensions. With no download or software installation required, you can optimize your images directly from your browser—perfect for web developers, e-commerce sellers, content creators, and everyday users.

### ✨ Key Features

* **⚡ Efficient Compression**: Significantly reduce file size while maintaining optimal visual quality (supports JPG, PNG, WEBP, and more).
* **📐 Custom Resizing**: Easily adjust width and height with optional aspect ratio lock to meet platform-specific requirements.
* **🔒 Privacy First**: Your files are processed securely with strong privacy guarantees.
* **🚀 Instant & Web-Based**: Clean browser interface compatible with both desktop and mobile devices.
* **🎯 Drag & Drop UI**: Ultra-simple workflow—drag, drop, optimize, and download.

### 🛠️ Common Use Cases

- **Web Performance & SEO**: Reduce load times and boost search engine rankings with lighter images.
- **Form & Attachment Uploads**: Easily bypass strict file upload limits (e.g., under 2MB).
- **Social Media Content**: Quickly fit images to optimal sizes for Instagram, Twitter, LinkedIn, etc.

## 🇨🇳 中文说明

### 📌 项目简介

**Downsize Image** 旨在帮助用户快速降低图片文件大小（KB/MB）并调整图像尺寸。无需下载或安装任何软件，直接在浏览器中即可快速完成图片优化，非常适合网页开发者、电商卖家、社交媒体创作者及需要批量缩小图片体积的日常用户。

### ✨ 核心功能

* **⚡ 高效图片压缩**：在尽可能保持原图高画质的前提下，显著减少文件体积（支持 JPG, PNG, WEBP 等主流格式）。
* **📐 自定义尺寸调整**：自由修改图片宽度与高度，支持保持宽高比，轻松适配不同平台规范。
* **🔒 隐私与安全保障**：注重用户隐私，确保处理过程安全无忧。
* **🚀 免安装/即开即用**：纯 Web 界面，完美兼容桌面端与移动端浏览器。
* **🎯 简单直观的 UI**：极简界面设计，支持拖拽上传，一步完成压缩与下载。

### 🛠️ 常见使用场景

- **网站与博客优化**：降低图片体积，提升网页加载速度与 SEO 表现。
- **系统/邮件附件上传**：轻松突破各类平台对上传文件体积（如 2MB 以内）的限制。
- **社交媒体配图**：快速适配不同社交平台的最佳图片展示尺寸。
